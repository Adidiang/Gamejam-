# 灵感涌现ing

经营一个游戏开发社团，用十二个月把脑洞变成自己的作品。

基于 **Godot 4.7.2 / GDScript** 的一年可玩原型：四名社员、岗位分配、好感养成、技能学习、游戏开发、Bug 修复、阶段试玩与年末评奖。

## 运行游戏

1. 安装 Godot 4.7.2，使用普通版或 .NET 版均可；本工程使用 GDScript。
2. 导入 [`灵感涌现ing/project.godot`](./灵感涌现ing/project.godot)。
3. 按 **F5** 运行，创建作品并开始第一年。

Windows 本机也可双击 [`灵感涌现ing/启动游戏.cmd`](./灵感涌现ing/启动游戏.cmd)。启动器目前使用开发机 F 盘的引擎路径；其他成员请直接使用 Godot 导入，或修改 `灵感涌现ing/tools/launch.ps1` 中的路径。

## 协作说明

提交源码、场景和 Godot 资源标识文件；不要提交 `.godot` 缓存、`saves` 存档、`qa` 测试截图、日志和导出包。相关排除规则已包含在 `.gitignore` 中。

人物和活动室采用代码绘制，按钮音效由代码合成。中文显示使用本机系统字体；跨平台发布前需要配置可分发的中文字体。
