# 灵感涌现ing

经营一个游戏开发社团，用十二个月把脑洞变成自己的作品。

基于 **Godot 4.7.2 / GDScript** 制作。当前默认入口为新的界面骨架：开始页的“开始游戏”按钮、以活动室背景图铺满的四个人物矩形入口、显示四项能力（白值与绿色增幅后两列，每点好感 +1%）、好感度（上限 50）和三个技能位的人物资料页，以及主界面右上角的年月与其下方的全局灵感点数显示、画面下方排期按钮左侧的当前作品名字与类型题材及作品四项属性（游戏性、创新性、表现力、Bug），以及右下角“排期”打开的工作分配表（拖动角色圆形或点击拿起再点击放下，调整玩法、美术、音效、修复四项职责）。排期中的“下一回合”结算全员岗位工作并推进月份，随后自动滚动展示左侧头像与右侧产出动效，展示结束后返回主界面。

人物页的“分配任务”打开右侧任务列表，支持美术概念设计：通用确认框取消后留在列表，确认后消耗 1 点回合行动步数，显示立绘和持续 1 秒的进度条，再只展示任务产出。任务不推进月份、不结算职责或获得每月灵感；通过排期中的“下一回合”统一结算并推进月份。全社团每回合隐藏的行动步数默认为 1，耗尽时“分配任务”按钮变灰，点击弹出“本回合已行动”小框，点击任意位置或 2 秒后自动关闭，下一回合恢复为 1，不累积。每年全社团只能执行一次此任务，次年恢复次数。表现力产出为增幅后的脑洞＋美术，创新性为该值×clamp(脑洞÷max(美术, 1), 0.1, 2)，系数限制仅适用于此任务。

此前的一年可玩原型保留在 `灵感涌现ing/scenes/main.tscn`，可在编辑器中打开该场景后按 F6 运行；其旧行动列表不作为当前任务系统入口。

人物页另有“邀约”按钮，与任务共享回合行动步数。确认后复用立绘与 1 秒进度条展示邀约结果，不推进月份或结算职责。邀约固定增加 10 好感，连续邀约同一人也为 +10，好感上限 50；邀约无年度次数限制，下一回合恢复步数后可再次执行。任一行动耗尽步数后，两个按钮都变灰，点击弹出“本回合已行动”小框。

## 运行游戏

1. 安装 Godot 4.7.2，使用普通版或 .NET 版均可；本工程使用 GDScript。
2. 导入 [`灵感涌现ing/project.godot`](./灵感涌现ing/project.godot)。
3. 按 **F5** 全屏运行，点击“开始游戏”，先在全屏游戏选择页自由输入作品名，并各选一种类型和题材，确认后进入主界面。再点击 a、b、c、d 中任一矩形进入对应人物资料页；点击“关闭”返回主界面。点击右下角“排期”打开工作分配表调整职责，点击弹窗外的部分返回；点击“下一回合”推进月份并查看逐人工作产出，结束后点击“确认”。十二月工作确认后自动进入下一年的游戏选择页。可用 Alt+F4 退出游戏。

Windows 本机也可双击 [`灵感涌现ing/启动游戏.cmd`](./灵感涌现ing/启动游戏.cmd)。启动器优先使用开发机 D 盘的 Godot 4.7.2，保留 F 盘候选路径；其他成员请直接使用 Godot 导入，或修改 `灵感涌现ing/tools/launch.ps1` 中的路径。

旧原型保留一年 12 回合流程。新人物资料统一填写在 [人物表](./灵感涌现ing/data/characters.json)，字段说明见 [填写指南](./灵感涌现ing/data/README.md)。人物 a 已填入绵羊梦游者“代号sheep”，编程／脑洞／美术／音乐为 10／100／20／10，题材偏好为奇幻、科幻；三个技能只展示白日梦、梦境讲述、梦想家及“机制待实现”提示，暂不执行效果或收取灵感。其余三人仍为零能力占位。[技能系统](./灵感涌现ing/scripts/skills/README.md)已支持自动解锁、灵感习得及立项／任务／职责／评奖触发（每人三个技能，门槛为 0／20／50，好感度上限 50），具体机制后续填写并验证。

灵感由社团共享，初始 2 点、每回合获得 1 点，技能消费同一余额。Bug 暂为没有额外用途的白板数值，只记录增加与修复（主界面下方实时显示游戏性、创新性、表现力与 Bug 的累计值），不影响开发产出、评分、奖项或奖励。

## 协作说明

提交源码、场景和 Godot 资源标识文件；不要提交 `.godot` 缓存、`saves` 存档、`qa` 测试截图、日志和导出包。相关排除规则已包含在 `.gitignore` 中。

人物立绘由人物表中的资源路径读取，主界面背景取自 `assets/backgrounds/`，旧原型的活动室仍由代码绘制，按钮音效由代码合成。中文显示使用本机系统字体；跨平台发布前需要配置可分发的中文字体。
