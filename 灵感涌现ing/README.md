# 灵感涌现ing

Godot 4.7.2 / GDScript 原生游戏。一年可玩原型 v0.1。

## 启动

- 双击 `启动游戏.cmd` 直接试玩，默认窗口 1280 × 800，可调整大小。
- 双击 `打开编辑器.cmd` 打开 Godot 工程；也可以在 Godot 导入本目录的 `project.godot`，按 F6 或 F5 运行主场景。
- 启动器优先使用 `F:\GamejamWithWu` 下的 Godot 4.7.2，找不到时使用 `F:\gamejam` 下的同版本。移动引擎后请修改 `tools/launch.ps1`。
- 这是使用本机引擎启动的工程版，不是独立 Windows 导出包。

## 已实现

1. 年初输入作品名，选择类型与题材，预览并结算社员偏好。
2. 四名有独立能力、偏好、形象和台词的成员：阿序、小满、青禾、声声。
3. 点击社员卡或活动室中的成员进行选择；免费调整玩法、美术、音效、修复岗位。
4. 每月一次行动：邀约、玩法打磨、原型实验、风格设计、配乐制作、集中测试。
5. 执行前预览完整回合的全员产出、Bug 变化和效率。
6. 好感提高能力；20 好感解锁个人专长技能，消耗 6 灵感学习，专长岗位产出 +20%。
7. Bug 达到 12 / 24 时，自动开发效率降低；任务测试先执行，岗位修复与开发同时结算。
8. 4 月与 8 月试玩达标奖励、12 月年末评奖、三项评分、Bug 扣分、获奖条件与历史手记。
9. 自动存档、备用存档恢复、继续游戏与重新开始。
10. 原创代码绘制的活动室和人物，以及可关闭的合成按钮音效。

## 操作与目标

点击一名成员，在右侧选择行动，然后点击“执行行动，结束本月”。每次执行之后，四名成员都会按各自岗位自动开发。调整分工、查看说明和学习技能不消耗回合。

最佳游戏奖需要总分不低于 80，游戏性、创新性、表现力的评分均不低于 50，且 Bug 不多于 5。没拿到最佳游戏也有完整结局，可以查看全年制作手记后再挑战。

表现力由视觉与听觉共同决定：`0.5 × (视觉 + 听觉) + min(视觉, 听觉)`。原始属性 210 点对应单项评分 100；综合权重为 40% / 30% / 30%，再扣除 `min(40, 2 × Bug)`。

## 第一版范围

这版验证一年 12 回合主循环，每名成员只有一级技能。三年继承、两名新成员招募、50 / 100 好感技能、拖拽分工暂未加入，与策划案中“一年原型”阶段一致。数值沿用提案起始值，仍需要真人试玩平衡。

界面为 1440 × 900 设计画布，保持比例缩放。Windows 使用系统微软雅黑，不将系统字体打包再分发。若移植到没有中文系统字体的平台，需要添加授权允许分发的中文字体。

## 存档

工程版保存至 `saves/club.json`，上一份有效存档备份为 `saves/club.json.bak`，测试数据单独写入 `qa/test_save.json`。关闭后在标题页选择继续。主存档损坏时尝试备份。

开始新游戏会覆盖当前进度。存档只包含作品和成员数据，不访问网络。当前 `res://saves` 位置适用于可写的本地工程；正式导出到只读安装目录前，应改用 `user://` 并进行导出平台验收。

## 工程结构

```text
project.godot              工程入口与窗口设置
scenes/main.tscn           主场景
scripts/game_model.gd     确定性结算、预览、评分和状态校验
scripts/main.gd           界面、交互、报告与游戏流程
scripts/room_view.gd      原创活动室与人物绘制
scripts/save_store.gd     存档写入与备份恢复
scripts/audio.gd          原创合成 UI 音效
tests/test_game.gd        规则与存档回归检查
tools/launch.ps1          本机启动入口
```

静态配置及公式集中在 `game_model.gd`，UI 不直接增加开发收益。预览与执行调用同一个纯数据结算函数；结算阶段和月份校验阻止重复提交。

## 验证

双击 `运行测试.cmd` 运行规则测试。覆盖预览隔离、示例数值、Bug 阈值、技能购买、连续邀约、重复提交、评分、完整 12 回合、JSON 往返和损坏存档恢复。

图形自动试玩命令（在引擎路径执行）：

```powershell
& 'F:/GamejamWithWu/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64_console.exe' --path 'F:/Gamejam社团/灵感涌现ing' --resolution 1440x900 -- --ui-smoke
```

图形测试不读写玩家存档，截图输出到 `qa/`。自动验证不能替代真人对玩法乐趣和难度曲线的测试。
