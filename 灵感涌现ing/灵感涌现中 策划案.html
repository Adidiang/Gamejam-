游戏社团策划案

一、核心内容

扮演游戏社团，依靠成员能力制作游戏，在有限时间（3 年，36 个回合）内尝试夺得游戏大赛最佳游戏奖。

补充说明：

  • 回合行动：玩家固定开发三款游戏，每款固定一年即 12 个回合。每回合可选择一名成员行动一次。每个回合行动结束后，每位成员会自动根据其职责为当前游戏增加属性。

玩法曲线：

阶段说明
第一年（筹备环节）几乎不存在夺冠可能性，主要用于吸引新成员、积累“灵感”点数、提升成员好感度并解锁技能。
第二年熟练玩家可以尝试直接夺冠。大多数情况下，在此阶段确定成员组合，集中资源强化。
第三年（冲分阶段）利用前两年的积累尝试以尽可能高的分数夺冠。

6. 评奖界面

年末自动弹出。十二月工作确认后，先进行一次 Bug 判定：命中时弹出提示，指出大量 Bug 造成了灾难性的体验，作品因此获得特质「BUG灾难」；随后按「最佳游戏提名 → 最佳美术 → 最佳游戏」的顺序依次弹出今年所获奖项，每个奖项只显示奖项名称与它带来的灵感数量；未获得的奖项直接跳过，没有获得任何奖项时只显示未获奖、不显示灵感。灵感在结算时直接计入社团，奖项允许同时获得、奖励累加，展示结束后进入下一年的游戏设计界面。

顺序奖项条件灵感
1最佳游戏提名游戏性 + 创新性 + 表现力 达到 3000+20
2最佳美术表现力达到 4000+30
3最佳游戏游戏性与创新性之和达到 10000，且表现力达到 2000+50

三、游戏

1. 属性

游戏性、创新性、表现力、bug。

年度评奖直接使用作品属性，1:1 换算：分项就是游戏性、创新性、表现力的当前数值，不额外折算成百分制。作品只有游戏性、创新性、表现力与 Bug 四项属性，最佳美术看的就是表现力（美术与音乐岗位产出的都是表现力）。评奖比较三类数值：三项之和、游戏性与创新性之和、表现力。

Bug 会触发「BUG灾难」：年末结算后 Bug 在 0～20 时不判定；21～100 时命中概率为（Bug 数量 − 20）%，即 21 只对应 1%、100 只对应 80%；100 以上恒为 80%。命中后作品获得特质「BUG灾难」，计算该游戏分数时各分项与各项之和均乘 0.5，因此可能只剩提名、甚至一奖不得。Bug 本身不影响每月产出与修复规则。

每款游戏只结算一次：评奖结束后进入下一年，新作品的属性与 Bug 从零开始，成员成长、好感度、已习得技能与社团灵感保留，历史作品的产出与评奖结果归档保留。

数值转换单元：任何由成员属性算出的产出（岗位工作、任务或其他来源），都要先经过同一个转换单元，再交给其他 buff（技能加成、翻倍等）。顺序固定为「计算规则 → 转换单元 → 其他 buff」，同一份产出在生命周期里只转换一次，buff 不再重复换算。转换系数取 3 个 0.5～1.5（含端点）均匀随机数的平均值（Irwin-Hall 近似），整份产出乘以同一个系数后输出，结果保留 4 位小数（保证存档往返数值完全一致）。

岗位职责产出（使用成员好感增幅后的最终属性，每月一次）：

职责产出
玩法开发游戏性 +（0.7 编程 + 0.5 脑洞）；创新性 +（1.2 脑洞）；Bug +（（脑洞 − 编程）× 0.1，向下取整）
美术开发表现力 +（0.8 美术 + 0.2 脑洞）；创新性 +（0.3 美术 + 0.2 脑洞）
音乐开发表现力 +（0.8 音乐 + 0.2 脑洞）；游戏性 +（0.3 音乐 + 0.2 脑洞）
Bug 修复Bug −（1 × 编程）

表现力是作品属性之一，由美术岗位、音乐岗位与美术概念设计任务直接产出。美术概念设计任务产出：表现力 = 脑洞 + 美术，创新性 = 表现力 × clamp(脑洞 ÷ max(美术, 1), 0.1, 2)。

全局资源：灵感

灵感是一种可获得、累积和消费的全局资源，由社团共享，不属于单个人物或某款游戏的属性。主界面在时间下方显示当前拥有的灵感点数，获得或消费后刷新。

每个回合行动结束后，每位成员会根据其职责为当前游戏增加属性。

2. 类型与题材

比如剧情向 + 奇幻。

对游戏本身无影响，但会影响喜欢此类型和题材的成员的好感度，以及影响吸引到哪些新成员。
