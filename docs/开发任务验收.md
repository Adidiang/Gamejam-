## 本轮实际开发变更

- `tools/launch.ps1`：支持指定引擎、环境变量及 PATH，测试前导入资源。
- `export_presets.cfg`：Windows x86_64 Release 预设、资源内嵌、保留运行数据并排除开发资料。
- `tools/build_windows.ps1`：导入、可选回归、导出、原生启动检查、许可证、构建哈希和 ZIP；修复 Windows PowerShell 的退出码及压缩接口兼容问题。
- `tools/verify_windows.gd`：验证打包资源的年度流程，明确记录编辑器／原生运行模式。
- `tests/test_sheep_skills.gd`：将过时的旧存档兼容断言与现有 v7 拒绝缺失字段的规则对齐，没有放宽模型校验。
- README、引擎许可证和 Godot 资源 UID。

本轮没有新增角色技能、改变数值、接入新存档流程或实现三年结束。

## 后续开发顺序

1. 明确三年结束时机及判定口径，先补齐 36 回合结束的模型与界面闭环。
2. 针对结束状态补充有意义的回归：不能进入第四年、年度档案保留、终局重复操作不重复结算。
3. 按角色 ID 接入美术交付资源，检查选人、人物页、主界面与结算展示。
4. 交接源码分支或补丁，并用普通开局完成一局真人 36 回合验收；不靠全员招募、满好感和无限灵感测试样本代替正常体验。

`AGENTS.md` 要求“影响核心玩法或涉及未明确的设计决策时，先说明差异并向用户确认”。因此三年结束时机的未定义部分需要明确后再实现，其余工程交接不受影响。
